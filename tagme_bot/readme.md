## Бот-разметчик в TagMe

**Автор:** Субботина Ирина

## Назначение

Бот-разметчик, который автоматически находит запущенные проекты/задания и размечает их с помощью LLM или других кастомных моделей/скриптов.

## Установка и запуск

1. Скачать и заполнить config файл по ссылке (добавить креды бота разметчика, url и auth_url = https://tagme.sberdevices.ru, организацию, в которой состоит бот разметчик) добавить в сам python проект. По этой же ссылке скачать wheel пакет, установить.
   https://tagme.sberdevices.ru/docs/sdk/installation.html

2. Для подключения к Tagme API добавить в проект .env с кредами бота разметчика и id организации, в которой состоит бот-разметчик. Обратиться к Субботиной Ирине.

Запуск 

python manager.py --stand cloud - для запуска менеджера по проектам и организациям в стенде cloud 

python manager.py --stand sigma - для запуска менеджера по проектам и организациям в стенде sigma 

python manager.py --stand sberdev - для запуска менеджера по проектам и организациям в стенде cloud, но с учетной записью razmetka_info (дополнительный бот в клауде)

Для запуска бота на определенную задачу запустить: python tagme_bot_script.py -t <id задачи в проекте> -o <id организации> --stand <название стенда: cloud, sigma, sberdev>

Пример:

python tagme_bot_script.py -t 1234567 -o 123456789 --stand cloud
