# Загрузка отчётов на FIR

После выполнения QA pipeline, Excel отчёты автоматически загружаются на сетевое хранилище FIR (через SMB протокол).

## Настройка

### 1. Создайте файл `.env` с учётными данными

В корне проекта `qa_agent/` создайте файл `.env` (можно скопировать из `.env.example`):

```bash
SMB_USERNAME=ваш_логин
SMB_PASSWORD=ваш_пароль
SMB_PORT=445
```

**Формат логина:**
- Если требуется домен: `SIGMA\\username` или `username@sigma.sbrf.ru`
- Если домен не нужен: просто `username`

### 2. Настройте путь к FIR в конфигурации проекта

В файле `configs/projects_config.json` для каждого проекта укажите путь на FIR:

```json
{
  "project_id": "...",
  "project_name": "...",
  
  "fir_upload": {
    "enabled": true,
    "base_path": "\\\\bordo105.sigma.sbrf.ru\\Vol6\\Dataset2\\Менеджер проекта\\Выделение споттерных слов на аудио_ос"
  }
}
```

**Параметры:**
- `enabled` (boolean) - включить/выключить загрузку на FIR для проекта
- `base_path` (string) - UNC путь к папке на FIR, куда будут сохраняться отчёты

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

Основные зависимости для FIR:
- `smbprotocol` - для работы с SMB протоколом
- `python-dotenv` - для загрузки переменных из .env

## Как это работает

1. **Pipeline выполняется** - создаётся локальный Excel отчёт в `data/<project_id>/reports/<date>/`
2. **Автоматическая загрузка** - если `fir_upload.enabled = true`, отчёт загружается на FIR
3. **Структура на FIR** - отчёты сохраняются в подпапки по дате:
   ```
   \\bordo105.sigma.sbrf.ru\...\Выделение споттерных слов на аудио_ос\
       └── 2026-05-31\
           ├── qa_report_7f2f0bb6_20260531_200316.xlsx
           └── qa_report_38068985_20260531_201046.xlsx
   ```

4. **Локальные файлы остаются** - для отладки и повторной загрузки

## Логирование

Все операции загрузки логируются:

```
[INFO] Загружаем отчёт на FIR: \\bordo105.sigma.sbrf.ru\Vol6\...
[INFO] Создана директория на FIR: \\bordo105.sigma.sbrf.ru\Vol6\...\2026-05-31
[INFO] Начинаем загрузку: qa_report_7f2f0bb6_20260531_200316.xlsx -> ...
[INFO] ✓ Файл успешно загружен на FIR
```

## Отключение загрузки

Чтобы временно отключить загрузку на FIR:

1. В конфиге проекта установите `"enabled": false`
2. Или не создавайте файл `.env` (загрузка не произойдёт)

## Troubleshooting

### Ошибка аутентификации

```
RuntimeError: Не заданы SMB_USERNAME / SMB_PASSWORD в окружении (.env)
```

**Решение:** Создайте файл `.env` с учётными данными (см. выше)

### Нет доступа к FIR

```
Error: [Errno 13] Permission denied
```

**Решение:** 
- Проверьте права доступа к папке на FIR
- Убедитесь, что логин/пароль верные
- Проверьте формат логина (с доменом или без)

### Папка не создаётся

```
Error creating directory on FIR
```

**Решение:**
- Убедитесь, что базовый путь `base_path` существует
- Проверьте формат пути (UNC: `\\\\server\\share\\folder`)
- Убедитесь, что у пользователя есть права на создание папок

## Безопасность

⚠️ **ВАЖНО:**
- Файл `.env` **не должен попадать в git** (уже в `.gitignore`)
- Не храните пароли в открытом виде в других файлах
- Не публикуйте `.env` в общедоступных местах
